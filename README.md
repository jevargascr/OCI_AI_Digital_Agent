# OCI AI Digital Agent

## Introducción

Este proyecto tiene como objetivo demostrar cómo construir un **chatbot inteligente y especializado** utilizando **Oracle Cloud Infrastructure (OCI)**, integrando el servicio de **Generative AI Agents Service** con la **RAG Tool (Retrieval Augmented Generation)**.  

La propuesta consiste en transformar el conocimiento existente de una organización —por ejemplo, el contenido de su sitio web— en una **base de conocimiento estructurada** en formato de archivos HTML. Esta información se convierte en el insumo principal para el agente, quien mediante la **RAG Tool** puede acceder a ella de manera dinámica y contextual.  

De esta forma, el chatbot no se limita a respuestas genéricas, sino que actúa como un **asistente virtual especializado en el negocio del cliente**, capaz de resolver dudas frecuentes, explicar productos y servicios, e incluso guiar al usuario en procesos clave de la organización.  

## Motivación

Los asistentes digitales tradicionales suelen estar limitados por respuestas predefinidas o flujos rígidos. Con **Generative AI Agents Service** y la **RAG Tool** se habilita un enfoque más flexible y poderoso, que permite:  
- **Ampliar el conocimiento del modelo** con documentación interna y fuentes web del cliente.  
- **Reducir alucinaciones** al basar las respuestas en información verificada directamente desde la organización.  
- **Ofrecer experiencias personalizadas y confiables** a usuarios y clientes finales.  
- **Soporte multi-idioma**, permitiendo que el asistente interactúe con usuarios en diferentes lenguas de manera natural y fluida, ampliando el alcance a audiencias internacionales.  

## Alcance del Proyecto

Este chatbot está diseñado para servir como un ejemplo práctico de integración de **servicios OCI** y buenas prácticas de **arquitectura de IA generativa**, incluyendo:  
- Descarga y procesamiento del **sitio web del cliente** como fuente de datos base.  
- Implementación de un **agente conversacional** con Generative AI Agents Service.  
- Configuración de la **RAG Tool** para enriquecer respuestas con la información contenida en los HTML del sitio.  
- Desarrollo de una **aplicación intuitiva** que presentará el asistente al cliente final como un **asesor digital experto en su negocio**.  

## Beneficios Clave

- **Escalabilidad y seguridad** al estar construido sobre OCI.  
- **Aprovechamiento del conocimiento ya existente** en el sitio web del cliente.  
- **Acceso controlado y contextualizado** a información empresarial, garantizando cumplimiento y privacidad.  
- **Mejor experiencia de usuario**, con respuestas relevantes, claras, multi-idioma y enfocadas en el negocio del cliente.
